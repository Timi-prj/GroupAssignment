# RBF-SVM模型卡：Mushroom

## 原理与适用性

RBF-SVM 寻找间隔较大的分类边界，并通过径向基核度量样本相似度，从而学习非线性边界。预测类别由决策函数符号确定，AUC 使用连续决策分数。

8124 条样本和 115 个 One-Hot 特征属于中小规模高维稀疏输入，RBF 核可以学习逻辑回归未显式表达的属性交互，形成线性与非线性的直接对照。

## 超参数

| 参数 | 设置 |
|---|---|
| kernel | RBF |
| C | 内层 5 折从 0.1、1、10、100 中选择 |
| gamma | 内层 5 折从 scale、0.001、0.01、0.1 中选择 |
| probability | False；AUC 使用 decision_function |

所有输入特征在训练折内 One-Hot，`handle_unknown='ignore'`；正类为 poisonous（1），随机种子为 42。内层调参以 F1 选优。

## 实际参数与结果

- 80/20 训练部分选出的参数：`C=1`、`gamma=scale`。
- 10 折外层各折参数见 `cv_fold_metrics.csv`，没有使用完整数据统一调参。
- Holdout F1=1.000000，ROC-AUC=1.000000。
- 外层 10 折 F1=1.000000 ± 0.000000，ROC-AUC=1.000000 ± 0.000000。
- 各外层折训练耗时合计 174.97 秒；硬件与软件版本见 `run_metadata.json`。

## 局限

蘑菇属性没有大小关系，必须先正确编码；C 和 gamma 会影响边界复杂度，因此必须在训练折内调参，且模型系数不像逻辑回归那样直观。
