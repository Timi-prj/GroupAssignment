# Mushroom Apriori 无监督关联分析

## 研究问题

哪些蘑菇属性经常共同出现，哪些属性组合与可食（`class=e`）或有毒（`class=p`）存在强关联？

## 方法与口径

- 每条样本转换为 `属性=取值` 项目集合，类别也作为项目参与共现挖掘，但不作为分类器训练标签。
- 使用 Apriori 的“频繁项集的子集必频繁”性质逐层搜索，最大项集长度为 3，避免规则爆炸。
- 参数：`min_support=0.20`、`min_confidence=0.80`；只保留后件为单一 `class` 项目的规则。
- 输出 Support（组合出现比例）、Confidence（条件出现时结论出现比例）、Lift（关联相对独立情形的增强倍数）。
- 全量数据用于描述性模式发现，不做交叉验证，不参与分类模型 F1 排名。高关联不表示因果关系，也不直接等价于现实鉴定规则。

## 交付

`src/a2_mushroom/apriori.py` 为可复现入口；`artifacts/a2_mushroom/apriori/` 保存频繁项集、全部筛选规则、按类别规则、Top 规则图和结果摘要。

方法参考：Duy 等（2023）以 Mushroom 为案例研究 Apriori 规则质量，https://doi.org/10.1007/978-981-99-3091-3_20 。本实验独立实现并重新计算，不引用其数值结果。
