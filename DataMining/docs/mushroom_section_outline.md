# Mushroom 部分大纲与材料核查

## 一、建议正文结构

### 1. 数据与预处理
- 8124 条样本、21 个有效名义属性、两类近似平衡。
- `ReplaceMissingValues` 补 `stalk-root`，`RemoveUseless` 删除 `veil-type`；J48 原生处理名义属性，逻辑回归/KNN 在训练折内 One-Hot 为 115 维。
- 用 J48 原始/清洗后对照说明预处理作用，不把“未提分”写成预处理无效。

### 2. 方法与评估
- 分类：ZeroR（基线）、J48-top9、逻辑回归、KNN。
- 无监督：Apriori，Support≥0.20、Confidence≥0.80、最大项集长度 3。
- 分层 10 折 + 80/20 holdout，seed=42；以有毒类 F1 为主，ROC-AUC 为次，并报告混淆矩阵。
- Weka 与 sklearn 的具体折索引不同，只比较汇总结果，不声称跨工具配对显著性。

### 3. 结果与模型选择
- 插入统一 F1/ROC-AUC 对比图和模型表。
- 三种非基线模型均满分；按简单、快速原则推荐逻辑回归，J48-top9 作为可解释替代。
- KNN 写明 `k=1～9` 并列满分，`k=1` 是并列后的默认记录，不宣称唯一最优。

### 4. 关联规则与讨论
- 插入 Apriori Top 规则图，各解释一条可食和有毒规则。
- 强调 Support/Confidence/Lift 的含义及“关联不等于因果”。
- 满分仅说明基准数据易区分，不外推为现实蘑菇鉴定能力。
