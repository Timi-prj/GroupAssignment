# 规范

## 模型卡

### ① 原因

- **概要介绍**：算法原理 2–3 句 + 超参数设置表
- **为什么适合**：必须绑定数据集特征（不平衡度 / 属性类型 / 规模 / 维度），例如"RandomForest 对混合类型属性和 70:30 不平衡稳健"

### ② 训练方式 + 曲线图

⚠️ **关键提醒**：Weka 的树模型（J48、RandomForest）**没有"每批次 loss"**。全队需统一约定曲线口径（同步项之一）：

> PDF 明确允许用 Python 做可视化，只要建模与评估流程可复现并在报告中写明工具与参数即可。曲线图统一命名：`模型名_数据集名_curve.png`。

### ③ 结果展示（必需项）

- 混淆矩阵
- F1-score
- ROC-AUC
- 每张图配 2–3 句文字解读（演示时被提问的防线）

## 其他规范

1. **随机种子**：全队统一（seed=42），保证所有模型用相同的 CV 划分
2. **评估协议**：10 折分层交叉验证 + 训练/测试切分比例（80%切分），两个数据集相同
3. **最优模型选择标准**（A3/B3 共用）：主指标 F1（不平衡场景）→ 平手看 ROC-AUC  → 仍平手选更简单/更快的模型
4. **防数据泄露检查**：SMOTE/Standardize/监督离散化/特征选择必须包在 `FilteredClassifier` 内（PDF 红字要求），由 B2 在合并前逐项核查
